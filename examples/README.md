# Example roles

Four IDENTITY.md sketches, one per agent, from a real four-agent install. Copy the one closest to
your job into `IDENTITY.md` and rewrite it - they are here to show how narrow a working agent's
mission statement should be, not to be used as-is.

The pattern worth copying: each agent does one job, says explicitly what it does *not* do, and names
which other agent owns the work it is refusing. Agents with overlapping missions produce duplicate
work and contradictory memory.
